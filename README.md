# Abira Enterprises website

A responsive, static catalogue built with HTML, CSS and JavaScript using the supplied packaging images. All six service categories and all 112 individual reference images are included. Original images remain unchanged in the parent folder.

## Add your contact details

Edit `dist/settings.js`. Enter `whatsappNumber` as digits only, including country code (for India, 91 followed by the 10-digit number). Add `phone`, `email` and `city` if desired. Blank fields stay hidden. With WhatsApp or email configured, the enquiry builder provides a link to send the completed brief. Before configuration, it offers copy and download only. Republish after edits to update the hosted site.

## Preview locally

From this directory, run `node server.mjs` and visit http://127.0.0.1:4173. Stop with Ctrl+C. The deployment folder is `dist`.

## Content and imagery

Collection descriptions follow the supplied folder structure and overview image. Gallery images are labelled as style references, including photos carrying other brands. No customer endorsements, certifications, prices, manufacturing ownership, minimum orders or delivery promises have been invented. Confirm image permissions and final product specifications before using the catalogue in public marketing.

The enquiry form processes information in the browser. It does not store enquiries on a server or claim to send them. Downloaded briefs are local text files. Fonts use Google Fonts with system fallbacks.

Design references: https://packhelp.com/ (collection navigation and enquiry flow), https://noissue.co/ (brand-focused packaging presentation). The design and implementation are original to this site.
